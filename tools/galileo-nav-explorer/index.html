Galileo Navigation Explorer

Open a RINEX 3 navigation file (.yyl, *_EN.rnx or mixed) and inspect every Galileo I/NAV and F/NAV ephemeris: each value in the file explained, the data-source and health bits decoded, and the satellite position computed. Files are read in your browser and never uploaded.

Record layout follows RINEX 3.04 (Table A8, Galileo navigation message); orbit and clock computation follows the Galileo OS SIS ICD, section 5.1. Times are Galileo System Time (GST), with weeks aligned to GPS weeks as RINEX writes them. Positions are in the Earth-fixed frame of the broadcast ephemeris (GTRF, within centimetres of WGS84 here); latitude and height use the WGS84 ellipsoid.
